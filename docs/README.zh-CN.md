# dsh-electro-lab

**ElectroLab** —— 用于解决电工电子问题的 DSH（DeepSeek Harness）插件。

[English](../README.md) | [简体中文](README.zh-CN.md)

## 安装

```sh
dsh plugin --profile web add dsh-electro-lab
```

包发布后可用。
